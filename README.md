# Bézier installers

Public macOS installers for Bézier. The application source repository is maintained privately.

[Download Bézier v0.1.2](https://github.com/ahmedkhaledmohamed/bezier-releases/releases/tag/v0.1.2) for Apple Silicon or Intel Macs. Requires macOS 11.0 or later.

The release contains the original v0.1.2 installers. Both app bundles passed signature verification and macOS Gatekeeper assessment as notarized Developer ID applications. Installer checksums are listed in [SHA256SUMS](SHA256SUMS).

This repository distributes installers for manual download. It does not provide an automatic-update feed for older builds.
